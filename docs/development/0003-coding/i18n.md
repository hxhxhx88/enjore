# I18n

- **ALWAYS** wrap end user facing text in [Lingui macros](https://lingui.dev/ref/macro) `t` and `<Trans>`.
  - Prefer `<Trans>` to `t`.
- Use English for the source language in code.
- For admin website do not apply i18n, since it is used by internal users.

Some code examples are:

```tsx
import type { JSX } from 'react'
import { Trans } from '@lingui/react/macro'

export function MyComponent(): JSX.Element {
  return (
    <div className="flex-1 items-center justify-center gap-4">
      <Trans>Welcome!</Trans>
    </div>
  )
}
```

## Translate outside JSX in server components

- When a string is needed outside JSX (for example, metadata or a label prop), describe it with the `msg` macro and translate it with the instance returned by `setupI18n`. Lingui deprecated the `t(i18n)` form in v5; the lint rule `ts/no-deprecated` rejects it.

  ```tsx
  import { msg } from '@lingui/core/macro'
  import { setupI18n } from '@/lib/i18n'

  export async function generateMetadata({ params }: Pick<LayoutProps<'/[locale]'>, 'params'>): Promise<Metadata> {
    const { locale } = await params
    const { i18n } = await setupI18n(locale)

    return { description: i18n._(msg`A starter template for web applications.`) }
  }
  ```

## Return i18n messages from server actions

- Server actions have no route params and run concurrently, so never activate a locale on the global instance. `getRequestI18n()` from `@/lib/i18n` builds a private instance from the `APP_LOCALE` cookie that the proxy sets on every localized page visit.
- Describe every user-facing message a server action returns with `msg` from `@lingui/core/macro` and translate it with that instance.

  ```ts
  'use server'

  import { msg } from '@lingui/core/macro'
  import { getRequestI18n } from '@/lib/i18n'

  export async function actionVerifyCode(input: Input): Promise<Output> {
    const i18n = await getRequestI18n()
    // ...
    return { type: 'bad', message: i18n._(msg`The code is incorrect or expired.`) }
  }
  ```

- **Never** return plain, hardcoded English messages to end users.
